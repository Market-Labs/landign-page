# User Stories

## US01: View Product Value Proposition

As a visitor, I want to understand what MarketGo offers so that I can decide whether it fits my needs.

## US02: Explore Services And Benefits

As a visitor, I want to review the main services and benefits so that I can compare the solution quickly.

## US03: Review Plans

As a visitor, I want to see plan options so that I can choose the most appropriate next step.

## US04: Contact The Team

As a potential customer, I want to send my contact information so that the MarketGo team can follow up.
